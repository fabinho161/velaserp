# Renovar ERP

Aplicacao ERP SaaS para gestao de producao, estoque, vendas, financeiro, CRM, usuarios da empresa, planos e administracao.

## Documentacao

- [Documento 1 - Arquitetura](./docs/documento-1-arquitetura.md)

## Stack

- React + Vite
- Firebase Auth, Firestore e Storage
- Node/Express no backend
- Mercado Pago para pagamentos

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

O backend possui README proprio em [`backend/README.md`](./backend/README.md).
